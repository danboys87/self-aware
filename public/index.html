Self-Aware Trend System: Dashboard Live

Atau tempel CSV (time,open,high,low,close,volume)

Garis hijau/merah = SuperTrend adaptif (naik/turun). Panah = sinyal. Garis putus-putus = SL, TP1, TP2 dari sinyal terakhir; garis abu-abu = entry. Waktu pada grafik: UTC.

Data diambil lewat server setiap 30 detik (hanya candle yang sudah close). Jika server tidak terjangkau, halaman memakai data demo sintetik. Performa dihitung dari simulasi tanpa fee, hanya untuk membandingkan, bukan saran keuangan.

Grafik memakai TradingView Lightweight Charts™ (Apache-2.0).
